# Lively Chess

A Rather Lively Chess Set, version 8. The whole game is one self-contained page (index.html), with no outside files.

Version 8 adds Xbox Wireless controller play, for one or two controllers, on a Mac, an iPad or any browser that supports game controllers. Press any button to wake a controller.

- In menus: the D-pad or left stick moves the gold highlight, A picks, B goes back.
- On the board: the D-pad or left stick moves a square cursor (up is always away from you), A picks up a piece and A again puts it down, B drops it, X asks for a hint (or the tutor in Tutor Mode), Y undoes, View flips the board, Menu pauses. Bumpers and the right stick turn the camera, the triggers zoom, and clicking the right stick resets the view.
- Two Players: the first controller plays White and the second plays Black, each with its own cursor. With one controller, it plays both sides.
- If a controller drops and reconnects, it picks up where it left off. Trackpad, mouse and touch keep working as before.

Version 7 added Tutor Mode: play the computer at the level you choose, tap "What should I do?" before any move to see your best options explained in plain English, and get a note on how you did after every move. It all works offline.

Tutor Mode also has an optional box for typing your own questions. It is answered by Claude and needs your own Anthropic API key, which you paste into the game. The key is saved only in your browser on that device and is sent only to Anthropic. "Remove key" deletes it.

Play it at https://chrisvonderau.github.io/lively-chess/
