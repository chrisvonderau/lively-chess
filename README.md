# Lively Chess

A Rather Lively Chess Set, version 7. The whole game is one self-contained page (index.html), with no outside files.

Version 7 adds Tutor Mode: play the computer at the level you choose, tap "What should I do?" before any move to see your best options explained in plain English, and get a note on how you did after every move. It all works offline.

Tutor Mode also has an optional box for typing your own questions. It is answered by Claude and needs your own Anthropic API key, which you paste into the game. The key is saved only in your browser on that device and is sent only to Anthropic. "Remove key" deletes it.

Play it at https://chrisvonderau.github.io/lively-chess/
